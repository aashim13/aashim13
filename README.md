## 🚀 Projects

### 🏥 Italian Medicines Dataset & Analytics (AIFA)
Built a structured dataset from official Italian Medicines Agency (AIFA) data through a mix of manual extraction and automated web scraping. Imported the data into **Power BI** for an interactive dashboard, normalized it into a relational database, and wrote 5+ analytical SQL queries to surface insights on drug classification, contraindications, and equivalence groups.

**Tools:** Python · SQL (PostgreSQL/SQLite) · Power BI · Excel

---

### 🌍 CO₂ Emissions Analysis: Anomaly Detection & Forecasting
Analyzed daily CO₂ emissions across multiple countries using advanced time-series techniques. Normalized data by population and GDP, applied **SAX symbolic representation**, detected anomalies, identified structural breaks around the COVID-19 pandemic using **CUSUM**, clustered countries with **K-Means and Hierarchical Clustering**, and forecasted short-term emission trends with **LSTM neural networks**.

**Tools:** Python · Scikit-learn · TensorFlow/Keras · Pandas · Matplotlib

---

### ⚡ Smart Home Energy Forecasting Dashboard
Built a Decision Support System to predict appliance energy consumption using 4.5 months of IoT sensor data. Engineered lag features and temporal variables, developed a progressive model pipeline (Baseline → Random Forest → XGBoost → SARIMA), and deployed an interactive **Streamlit web app** for real-time scenario simulation.

**Tools:** Python · XGBoost · SARIMA · Streamlit · Pandas · Scikit-learn

### 📱 RealNotes — AR Memory Sharing iOS App
An iOS app that lets users place digital notes and stickers in physical spaces using **Augmented Reality**. Memories are anchored to real-world locations so others can discover them later. Built with ARKit, RealityKit, SwiftUI, and Firebase for real-time sync.

**Tech:** Swift · ARKit · RealityKit · SwiftUI · Firebase · CoreLocation
